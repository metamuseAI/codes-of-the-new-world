# Codes of the New World

Bilingual book landing page for **Codes of the New World — The Awakening Chapter** with a voice agent and subscriber sign-up flow.

## Local development

Install dependencies with pnpm, then run the landing page and API server using the workspace scripts documented in replit.md.

Secrets such as OPENAI_API_KEY, SESSION_SECRET, and DATABASE_URL must be configured as environment variables and are not stored in this repository.
